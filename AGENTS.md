# Agent Neutral Surface

This document carries the universal house rules that apply to all UI/UX work 
generated by this agent, regardless of project. It is the "agent-neutral surface" 
referenced in the accuracy report.

## Core House Rules

### 1. Token by Intent
- Destructive actions (Delete, Remove, Revoke) use `action.destructive` / 
  `component.button.destructive-bg`, **NEVER** `action.primary`
- Primary = the one main affirmative action; Secondary = neutral (transparent/outline, 
  dark text; **never a colored fill**); Danger = destructive, consistent everywhere
- Measured by `scripts/lint_intent.mjs`

### 2. One Theme, One Source of Truth
- Every page and component renders from the same `tokens/*.json` -> one CSS-variable 
  layer imported once at the app root
- No per-page palette, no hardcoded hex, px, or timing
- Measured by token consistency checks

### 3. Zero Emoji
- Absolute: zero emoji in any output
- Emoji are the number-one tell of machine-generated slop
- Em dash/en dash also prohibited in instruction surface
- Measured by `python3 scripts/check_no_emoji.py`

### 4. No Hardcoded Values
- No hex colors, px lengths, ms timings, or font sizes written directly
- All values must resolve through the token system
- Measured by `scripts/lint_hardcodes.py`
